# Component catalog

One line per component. Each guide lists props, variants, tokens, accessibility and examples. For the rules behind them, see [design-system.md](design-system.md).

| Component | Purpose | Guide |
|---|---|---|
| Badge | A small inline label that marks a card or states a short fact in a pill. | [src/components/Badge/Badge.md](../src/components/Badge/Badge.md) |
| Button | The single button component: a call to action that navigates or triggers an action. | [src/components/Button/Button.md](../src/components/Button/Button.md) |
| CurrencyTable | A two-column data table with an optional trend icon, a title and an update chip. | [src/components/CurrencyTable/CurrencyTable.md](../src/components/CurrencyTable/CurrencyTable.md) |
| FeatureCard | A compact card for a product feature: icon, title and a short description. | [src/components/FeatureCard/FeatureCard.md](../src/components/FeatureCard/FeatureCard.md) |
| Icon | An inline SVG icon that takes its colour from the surrounding text colour. | [src/components/Icon/Icon.md](../src/components/Icon/Icon.md) |
| PlanCard | A pricing card for one plan with a price, a note, an optional badge and a call to action. | [src/components/PlanCard/PlanCard.md](../src/components/PlanCard/PlanCard.md) |
| SectionTitle | A heading with an optional lead paragraph, coloured for the surface it sits on. | [src/components/SectionTitle/SectionTitle.md](../src/components/SectionTitle/SectionTitle.md) |
